# Flows

*Last updated: 2026-09-28*

1. **Write** — Yangi hikoya → title (address follows) → sections → Saqlash (draft).
2. **Check** — live preview beside the editor; Ko‘rish opens `/preview/{id}`.
3. **Publish** — Hozir nashr qilish, or Rejalashtirish with a local time; the worker publishes when due.
4. **Launch** — Sayt → turn off noindex, set base URL; or export the static site (ZIP) for any host.
