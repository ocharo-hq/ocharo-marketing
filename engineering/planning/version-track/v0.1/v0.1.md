### Iteration 5 — HTTP errors and publishing request feedback

- [ ] Failed request → one safe localized toast, settled skeletons and retained confirmed content
- [ ] Pending write → controls show progress while persisted rows/forms remain unchanged
- [ ] Successful write → independent projection read updates the appropriate data region
- [ ] Failed write → no row removal, form dismissal or completed-resource claim
- [ ] Refresh → initial background matches the mounted colour mode
- [ ] Endpoint/framework/proxy failure → ProblemDetails status, correlation and response headers remain valid

Implementation and automated evidence: [Ocharo HTTP request verification](../../../../../ocharo-platform/engineering/research/catalogue/2026-10-02-http-request-contracts.md).

### Iteration 6 — Ocharo suite frame

Marketing and Editorial adopt the frame Desk, Catalogue and Studio share, on `@wow-two-beta/fe` 0.0.32 with the
`theme-ocharo` glass ([architecture](../../../architecture/architecture.md#ocharo-frame-and-app-links)).

- [ ] Ability to move between Ocharo apps from the app button, with addresses each host serves at runtime
- [ ] Ability to find every section in a grouped sidebar, an icon rail, or a phone bottom bar with More
- [ ] Ability to choose appearance and interface language, and read app and API versions, in the account menu
- [ ] Ability to see the signed-in person's Desk name and email in the account menu
- [ ] Ability to sign this app out of Ocharo Desk and open the Ocharo account in a new tab
- [ ] Ability to work in light or dark without a flash of the other mode
- [ ] Unsaved post or story → a sidebar or bottom-bar section change still asks first
- [ ] Unsaved or saving editor → sign-out waits and says why; the edits stay
- [ ] Signed out or expired session → the page and its edits stay; Reconnect opens in a new tab

Executed results (2026-10-21, local only): Marketing backend 296 and Editorial backend 216 tests at the frame
change; after the 0.0.31 glass, identity and link-row change, Marketing frontend 22 files / 185 tests and Editorial
15 files / 59 tests, typecheck with the SFC check, lint, format check and both production builds. Browser passes on
scratch hosts with throwaway data covered both apps at 1440 px in light and dark and at 390 px, with the app,
account and More menus open. These checks do not establish owner acceptance, hosted SSO, or deployment.

0.0.32 glass phone bar (2026-10-21, local only): both phone bars take `BottomNavMenu variant="glass"`, so they keep the
theme's glass fill instead of losing it to the SDK's solid `bg-background`; the SDK supplies the glass-edge top border,
the upward `--glass-bottom-shadow` and the safe-area padding. Marketing frontend 22 files / 185 tests and Editorial
15 files / 59 tests, typecheck with the SFC check, lint, format check and both production builds (Editorial under
`/studio/`). A browser pass on scratch hosts with throwaway data at 390 px read both bars' computed glass fill, 24 px
blur, top edge and upward shadow in light and dark.
